## 🛠️ Tech Stack (เทคโนโลยีที่เลือกใช้)

การพัฒนา Chrome Extension ในมาตรฐาน **Manifest V3** จะเน้นการประมวลผลที่ฝั่งผู้ใช้งาน (Client-side) ทั้งหมดเพื่อความรวดเร็วและความปลอดภัยสูงสุด

* **Frontend UI:** HTML5 และ CSS3 (ใช้สำหรับสร้างหน้าต่าง Action Popup และหน้าต่างครอบโปร่งใสบนหน้าเว็บ)
* **Core Logic:** JavaScript (ES6+) หรือ TypeScript (ทำงานร่วมกับ Chrome Web APIs)
* **Chrome Extension APIs:**
* `chrome.contextMenus` (ระบบคลิกขวาที่รูปภาพ)
* `chrome.tabs` (จัดการการเปิดแท็บใหม่เมื่อเจอลิงก์)
* `chrome.scripting` (ฉีดสคริปต์หน้าต่างลากครอบเข้าไปในหน้าเว็บปัจจุบัน)


* **Image Processing:** HTML5 Canvas API (ใช้สำหรับอ่านค่าพิกเซลของรูปภาพและตัดภาพเฉพาะส่วนที่ลากครอบ)
* **QR Decoder Library:** **`jsQR`** (ไลบรารี JavaScript ที่เบาและเสถียรที่สุด ทำหน้าที่แปลงภาพ Data URL/Canvas ให้เป็นข้อความ)

## 📋 Functional Requirements (ข้อกำหนดฟังก์ชันการทำงาน)

| ID | ฟังก์ชันการทำงาน | รายละเอียดความต้องการ |
| --- | --- | --- |
| **FR-1** | **Context Menu Interaction** | เมื่อผู้ใช้คลิกขวาที่วัตถุประเภทรูปภาพ (`image`) บนเบราว์เซอร์ จะต้องมีเมนู "สแกน QR Code จากรูปนี้" ปรากฏขึ้น |
| **FR-2** | **File Upload Interface** | ในหน้าต่าง Popup ต้องมีปุ่มสำหรับเลือกไฟล์ภาพจากเครื่องคอมพิวเตอร์ (.png, .jpg, .jpeg) |
| **FR-3** | **Screen Overlay & Interaction** | เมื่อเปิดโหมดลากครอบ ระบบต้องเปลี่ยนเมาส์เป็นรูปกากบาท (+) และมีพื้นที่สีเทาโปร่งใสทับหน้าเว็บ เพื่อให้ผู้ใช้สามารถคลิกและลากเมาส์สร้างกล่องสี่เหลี่ยมได้ |
| **FR-4** | **Area Capture & Cropping** | ระบบต้องดึงพิกเซลจากพื้นที่หน้าจอเฉพาะที่อยู่ภายในกล่องสี่เหลี่ยมที่ผู้ใช้ลากครอบ แล้วแปลงเป็นภาพใหม่เพื่อส่งต่อ |
| **FR-5** | **QR Decoding Process** | ระบบต้องวิเคราะห์ภาพจากทั้ง 3 ช่องทาง (คลิกขวา, อัปโหลด, ลากครอบ) เพื่อถอดรหัสออกมาเป็นข้อความ (String) |
| **FR-6** | **Smart Navigation** | หากผลลัพธ์ที่ได้จากการถอดรหัสมีรูปแบบเป็น URL ระบบต้องเปิดแท็บใหม่และลิงก์ไปทียูอาร์แอลนั้นโดยอัตโนมัติ |
| **FR-7** | **Result UI & Notification** | หากผลลัพธ์ไม่ใช่ URL (เช่น รหัสผ่าน, ข้อความธรรมดา) ระบบต้องแสดงผลข้อความนั้นใน Popup พร้อมปุ่ม "คัดลอก (Copy)" และหากไม่พบ QR Code ต้องแสดงข้อความแจ้งเตือนอย่างชัดเจน |

## 👤 Use Case Diagram & Overview

* **Actor:** User (ผู้ใช้งานทั่วไปที่ติดตั้ง Extension บน Chrome)
* **Use Cases ทั้งหมด:**
1. **UC-1:** Scan via Context Menu (สแกนผ่านการคลิกขวา)
2. **UC-2:** Scan via File Upload (สแกนผ่านการอัปโหลดไฟล์)
3. **UC-3:** Scan via Screen Selection (สแกนผ่านการลากครอบพื้นที่)
4. **UC-4:** Copy Text to Clipboard (คัดลอกข้อความผลลัพธ์)

## 📝 Use Case Descriptions (คำอธิบายยูสเคสอย่างละเอียด)

เพื่อไม่ให้เนื้อหายาวเกินไป ผมจะเน้นเจาะลึกใน 2 ยูสเคสหลักที่คุณต้องการคือ **การอัปโหลดไฟล์** และ **การลากครอบหน้าจอ** ครับ

### Use Case Description: UC-2 Scan via File Upload

| หัวข้อ | รายละเอียด |
| --- | --- |
| **Use Case ID / Name** | UC-2: Scan via File Upload |
| **Actor** | User |
| **Pre-conditions** | ผู้ใช้เปิดหน้าต่าง Popup ของ Extension ขึ้นมาแล้ว |
| **Post-conditions** | ระบบแสดงผลลัพธ์ที่ได้จากรูปภาพ หรือเปิดลิงก์ไปยังแท็บใหม่ |
| **Main Flow (ขั้นตอนการทำงานปกติ)** | 1. ผู้ใช้คลิกที่ปุ่มอัปโหลดไฟล์ภาพบนหน้าต่าง Popup<br>

<br>2. ผู้ใช้เลือกไฟล์รูปภาพ QR Code จากคอมพิวเตอร์<br>

<br>3. ระบบดึงข้อมูลรูปภาพเข้ามาและวาดลงบนไฟล์ Canvas ลับในระบบ<br>

<br>4. ระบบส่งข้อมูลพิกเซลให้ไลบรารี `jsQR` ประมวลผล<br>

<br>5. ระบบตรวจพบข้อความใน QR Code<br>

<br>6. ระบบตรวจสอบและพบว่าเป็นลิงก์เว็บ (URL)<br>

<br>7. ระบบเปิดหน้าต่างแท็บใหม่ไปยังลิงก์นั้นทันที |
| **Alternative Flow (ทางเลือกอื่น)** | **[5a] ระบบตรวจพบข้อความที่ไม่ใช่ URL:**<br>

<br>- ระบบจะแสดงข้อความนั้นในหน้าต่าง Popup พร้อมปุ่ม Copy<br>

<br>**[5b] ไลบรารีถอดรหัสไม่สำเร็จ (ไม่พบ QR Code):**<br>

<br>- ระบบจะแสดงข้อความแจ้งเตือนว่า "ไม่พบ QR Code กรุณาลองใหม่อีกครั้ง" |

### Use Case Description: UC-3 Scan via Screen Selection (Crop)

| หัวข้อ | รายละเอียด |
| --- | --- |
| **Use Case ID / Name** | UC-3: Scan via Screen Selection |
| **Actor** | User |
| **Pre-conditions** | ผู้ใช้อยู่ในหน้าเว็บใดเว็บหนึ่งที่มี QR Code ปรากฏอยู่บนหน้าจอ |
| **Post-conditions** | พื้นที่ที่ถูกลากครอบจะถูกสแกน และแสดงผลลัพธ์ให้ผู้ใช้ทราบ |
| **Main Flow (ขั้นตอนการทำงานปกติ)** | 1. ผู้ใช้คลิกปุ่ม "ลากครอบเพื่อสแกน (Crop & Scan)" บนหน้าต่าง Popup<br>

<br>2. หน้าต่าง Popup ปิดตัวลง และระบบจะแสดงแผ่นใสสีเทา (Overlay) ทับหน้าเว็บปัจจุบัน<br>

<br>3. ผู้ใช้คลิกเมาส์ค้างไว้แล้วลากครอบพื้นที่ที่เป็นรูป QR Code<br>

<br>4. เมื่อผู้ใช้ปล่อยเมาส์ ระบบจะบันทึกพิกัดจุดเริ่มต้นและขนาดของกล่องที่ลาก<br>

<br>5. ระบบสั่งการแคปภาพหน้าจอในส่วนที่มองเห็นด้วยคำสั่ง `captureVisibleTab`<br>

<br>6. ระบบตัดรูปภาพ (Crop) เฉพาะพิกัดที่ระบุด้วย Canvas API<br>

<br>7. ระบบส่งภาพที่ตัดแล้วให้ไลบรารี `jsQR` ถอดรหัส<br>

<br>8. ระบบทำการแจ้งผลลัพธ์หรือเปิดลิงก์เว็บตามประเภทข้อมูลที่ได้ |
| **Exception Flow (กรณีเกิดข้อผิดพลาด)** | **[4a] ผู้ใช้กดปุ่ม Esc หรือคลิกนอกพื้นที่ลากครอบเพื่อยกเลิก:**<br>

<br>- ระบบจะลบแผ่นใส Overlay ออก และกลับเข้าสู่สภาวะปกติโดยไม่มีการสแกน |
